# 歌词注释指南（名词解释注行）

## 注行格式

- `[与锚句译文相同的时间戳]※ 名称（中文译名）：说明`，紧贴该句**译文行正下方**。
- 同一时间戳多行会同时显示（lx-music/PotPlayer），播放到该句注释自动浮现。
- **只注首次出现**，副歌/重复段不重复注。
- 文风：短句、含量；`「」` 引号；不写「注：」「原注：」等元话术；
  梗类给“字面义 + 圈内读法”两说；考据不到就收窄措辞，不编。

## 写入与校验

- 逐条定位锚句译文行（`lines.index("[ts]译文")` 取首次出现），在其下一行插入同 ts 的 `※` 行；
- 同一锚句下多条注释：连续插入；二次追加时**自下而上**（按位置倒序）处理，后插不影响前定位；
- 写后复读：`※` 行数 == 注释条数；抽 2–3 处确认紧跟锚行；BOM+CRLF 未破；
- 改动前备份（`.pre-notes` 分档，见维护指南）。

## 考据链路（按优先级）

1. **Genius 行注释**（歌圈考据深处；人名/品牌“到底是谁”常只有它写了）
   - 搜歌：`https://genius.com/api/search/multi?q=<artist> <title>` → 正则取 song id；
   - 取注释：`https://genius.com/api/referents?song_id=<id>&text_format=plain`
     （正文含控制字符，解析用 `json.loads(text, strict=False)`）；
   - 每个发行版页面独立（Slow / Speed Up / Remix…），注释可能只挂某一版，逐版试。
2. **外语圈译注**（如俄语圈 nikkur.ru）：逐句翻译带编号脚注，常有专名考据。
3. **网易云同步歌词**（行结构与时间戳标尺）：官方同段同样无行 ⇒ 本地“空白段”不是缺词；
   社区中文翻译可参照，但碎切/含糊处不可信。
4. **交叉验证**：结论 ≥2 处独立出处；仅一处强出处也可用，措辞留余地。

## 误听与碎切核对（读不通的 hook 怎么判）

- 症状：hook 读不成句（`Don me ain't don me…`）——先怀疑**人声采样被砍词**或听写稿
  照音记字；不要按字面硬翻（整段方向性翻车的常见来源）。
- 判据：官方词表里带前导 `-` 的碎片（`-don me`）＝被切过的词尾；同表未切的重复实例即真词
  （`called on me`）；粉丝 wiki 的 Trivia 常一句点破。
- 处理：**原文行保留表面形态**（听感对位）、**译文按真词翻**（语义对位）；
  表面义误导时加一条 `※` 说明（切了什么、真词是什么）。

## 坑

- 同名异物：检索第一义项常是无关词条（小镇/律所/名人），按上下文过滤，圈内身份优先。
- 注释文不写“据 X 站”式出处话术——结论直给；出处记在维护记录里。
- 重写带注文件时：整块重渲染会静默抹掉既有 `※` 行——先暂存、后按锚句回插。
