# 歌词库维护指南

> 本指南来自一个真实维护项目的经验总结（数百首双语歌词库，lx-music + PotPlayer 环境）。
> 工具：`rebuild_lib.py`（重建/回写）、`lrc_audit.py`（体检）。

## 1. 库布局与成品形状

- 歌曲文件成对：`曲名.flac/.mp3` + `曲名.lrc`；
- 子目录 `_orig_lrc/` = 原始下载与“改前备份”；
- 子目录 `_rebuild_work/` = 工作区（审计 JSON、对照报告、进度文件）。

成品 `.lrc` 形状：

```
[元数据头 ti/ar/al/by ...]
[原文行 与 中文译文行]        ← 相邻式（原文下紧贴译文）或 分块式（原文块+译文块）都合法
[注音块（罗马音/台罗/粤拼）]  ← 垫底，不翻译
```

- 播放器按时间戳排序渲染：**同一时间戳多行会同时显示**（所以两种排布都等效）；
- 译文行与原文行**同时间戳**；
- 有些库同时含“注释行”（`※ …`，见《歌词注释指南》）。

## 2. 硬规则

1. **编码**：成品一律 `utf-8-sig`（BOM）+ CRLF + 末尾换行。写回时保持原字节风格，
   否则播放器可能乱码/丢行。
2. **一条原文至多一种译文**。先检测再插：网易云同步歌词有两种双语格式——
   交替式与分块式，识别失误会插入双份译文。
3. **注音行不翻译**（罗马音/粤拼/台罗……），通常整块垫底。
4. **方言歌误判是首查项**：台语/粤语歌词是汉字行，会被“有汉字=已翻译”的检测
   误判为“已翻”——症状：某“单语”文件的第二块其实是注音而非普通话译文。
5. **改前必备份**，按改动性质分档，不覆盖旧档：
   - 整篇重译 → `.pre-v2`；二次重译 → `.pre-retrans`；加注释 → `.pre-notes`；
   - 同名档已存在则顺延序号（`.pre-notes2`）——每一层回滚点都要在。

## 3. 常见病症（体检信号）

| 信号 | 含义 | 处理 |
|:--|:--|:--|
| “以下歌词翻译由 XX 大模型提供” | 供应商机翻署名行 | 整篇重译，并删除宣传行 |
| 全库 `**` / `＊` | 打码（原文或译文） | 去马补真词（原力度保留） |
| `[awlrc:...]` 巨行 | lx-music 内嵌 base64，把整份歌词塞进一行 | 直接删行 |
| U+FFFD `�` | 替换符（解码事故） | 定位来源，人工修复 |
| 同时间戳 2 条独立译文 | 重复翻译 | 留正确的一条 |
| 注音块里混着译文行 | 杂行 | 清理 |
| 外文行无同时间戳中文同伴 | 缺译 | 补译（标题与词曲 credits 豁免） |

## 4. 三个工作程序

### 程序一 · 单文件诊断
读文件 → 列出块结构（元数据/原文/译文/注音）与排布 → 跑体检信号四查
（方言误判／机翻署名／打码／三计数）→ 分级：小洞定点修，整体不合格走程序二。

### 程序二 · 整篇重译（rebuild_lib）

```python
import os
os.environ["LRC_WS"] = "D:/music/歌词库"
import rebuild_lib as rl

# 1) 构建 {原文行文本: 新译文} 字典（键先做撇号/空白规范化，防匹配失败）
TR = {...}
out, stats = rl.render("曲名.lrc", TR, fmt="block", note_idx={12,13,14}, none_pats=[r"^作词", r"^作曲"])
if stats["missing"]:
    print(stats["missing"])      # 有原文行没配到键：补键重渲染
else:
    rl.commit("曲名.lrc", out, stats["bom"])   # 自动 .pre-v2 备份
```

要点：
- `missing==0` 才允许 commit；commit 成功后才更新你的进度清单；
- 重复副歌用同一译法；标题与词曲 credits 用 `none_pats` 豁免；
- 旧译文行会被丢弃，注音块原样垫尾；注音块里混入的孤立译文行要滤掉。

### 程序三 · 全库体检（lrc_audit）

```bash
python lrc_audit.py "D:/music/歌词库" --json audit.json
```

先做低风险机械清理（删宣传行、去马、清杂行），整篇重写走程序二，每首独立备份。

## 5. 坑

- **文件被播放器占用时写入会失败**：先暂停播放再改。
- **文件名以磁盘为准**：同名还有 `.flac/.mp3`，glob 后必须 filter `.lrc`；
  标签里合法、磁盘名里非法的字符会被去掉（`Don't say"lazy"` → `Don't saylazy`）。
- **重写带注文件**：整块重渲染会抹掉既有 `※` 注释——先暂存、重写后按锚句回插。
- 被点名“重新翻译”的已完工文件：先核原文（可能整段建立在误听稿上，见注释指南）。
